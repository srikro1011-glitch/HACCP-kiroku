カウンター整理表ボタンの登録

食べログノートのタイムスケジュールを、カウンターを隣同士に並べ直した見やすい表（3枚）にして、PDFで出せるボタンです。
食べログにログインしているPCやiPadのブラウザに、ボタンを1回登録するだけで使えます。食べログの予約は読むだけで、書き換えません。
PCの人iPadの人使い方

PC（Chrome・Edge）で登録

  1. ブックマークバーを出す（Ctrl＋Shift＋B）
  2. 下のオレンジのボタンを、ブックマークバーまでドラッグする
    整理表
  3. うまくいかないときは、ブックマークバーで右クリック →「ページを追加」→ 名前「整理表」、URLに上でコピーした文を貼って保存

iPad（Safari）で登録

  1. 上の「ボタンの文をコピー」を押す
  2. このページで、共有ボタン →「ブックマークを追加」→ 名前「整理表」、場所「お気に入り」で保存
  3. 左上のサイドバーボタン →「ブックマーク」→「お気に入り」→ 下の「編集」→「整理表」を押す → アドレスを全部消して、コピーした文を貼って「完了」
  4. iPadの「設定」→「Safari」→「お気に入りバーを表示」をオンにしておくと押しやすい

使い方（毎朝）

  1. 食べログノートにログインして、タイムスケジュールを開く
  2. ブックマークの「整理表」を押す → 画面が整理表に変わる
  3. 「PDFにする／印刷」を押す（iPadは印刷画面の共有から「ファイルに保存」でPDF）
  4. 終わったら「食べログノートに戻る」

上の「◀ 前の日／次の日 ▶」でほかの日も見られます。カウンターの並べ直しは当日だけで、ほかの日は食べログの席のまま出ます。

iPadをホーム画面のアイコン1つで開きたいとき（Userscripts）
  1. App Storeで「Userscripts」（無料）を入れて、1回開いて保存先を決める
  2. iPadの「設定」→「アプリ」→「Safari」→「機能拡張」→「Userscripts」をオン（許可するサイトに owner.tabelog.com）
  3. スクリプトを開く → アドレス欄の「ぁあ」かパズルのマーク →「Userscripts」→「インストール」
  4. 整理表を開く → 整理表が出たら、共有 →「ホーム画面に追加」
